1. MO HINH WINDOWS AO TREN O DI DONG (G:\MThu):
   - Thu muc goc he sinh thai:  G:\MThu\
   - Tat ca Phan mem / Games:   G:\MThu\Apps\
     (Chrome, Steam, Discord, AudioRelay, Client, Games...)
   - User Profile rieng biet:   G:\MThu\Users\Quân GM\
     (Chua toan bo AppData, Desktop, Documents, Downloads, .gemini, .antigravity-ide...)
   - File Menu danh sach app:   G:\MThu\menu.json (Che do AN - Hidden)
   - Khoa xac thuc o dia:       anhyeuempmt.tag   (Che do AN - Hidden + System)

2. TINH NANG KEO-THA FILE CAI DAT (.EXE / .MSI / .BAT):
   - Khi tai 1 file setup (Vi du: DiscordSetup.exe, ChromeSetup.exe, GameSetup.exe):
   - Chi can KEO VA THA truc tiep file setup do vao cua so QuinGM Menu.
   - He thong se tu dong hien thong bao xac nhan:
     + Tu dong chuyen huong duong dan cai dat vao: G:\MThu\Apps\<TenApp>\
     + Dieu huong bien moi truong AppData, LocalAppData, UserProfile ve G:\MThu\Users\Quân GM\
   - Nhan YES, trinh cai dat se mo len cho ban bam Tiep tuc / Hoan tat.
   - Khi cai xong, Menu se tu dong hoi them ung dung vao danh sach Menu!

3. GIAO DIEN SETUP WIZARD (CAU HINH MENU NHANH):
   - Bam nut [⚙ Setup Menu] tren thanh Header cua ung dung:
   - Tool se quet toan bo thu muc trong G:\MThu\Apps\
   - Ban chi can click vao tung thu muc, chon file .exe can hien thi tren Menu.
   - File se vao "Hang cho" (co the xoa hoac sap xep tuy y).
   - Bam "Hoan tat Setup", ung dung se tu dong tao va cap nhat menu.json o che do An!

4. TINH NANG TICK CHON VA XOA THE HANG LOAT:
   - Moi the ung dung deu co 1 o tick vuong phat sang Neon o goc tren ben trai.
   - Nut "Chon Tat Ca" va "Xoa Hang Loat" nam ngay tren thanh Header.
   - Khi tick chon, the phat sang vien Neon Cam sang ro rang.
   - Bam "Xoa Da Chon" se hien popup xac nhan tuy bien Neon Auburn cuc dep.

5. TOOLTIP & MODAL HOVER TUY BIEN CAO CAP (NEON AUBURN):

     Hien tooltip mini rieng biet dong bo phong cach Neon.
